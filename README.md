# MVC PHP Native - Data Film

Aplikasi CRUD sederhana untuk mempelajari pola Model-View-Controller pada PHP Native dengan tema data film (Hamnet, Aftersun, Manchester by the Sea, Bridge to Terabithia, Beautiful Boy).

## Kebutuhan
- PHP 8.0 atau lebih baru
- MySQL/MariaDB
- Web server lokal (XAMPP / Laragon)
- Git

## Instalasi
1. Salin proyek ke folder web server (`htdocs` atau `www`).
2. Import `database/bioskop.sql` ke database MySQL.
3. Sesuaikan konfigurasi pada `config/database.php`.
4. Buka `http://localhost/mvc-film/public/index.php`.
